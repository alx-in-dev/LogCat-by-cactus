# Changelog

## Не выпущено
- Поиск в фильтре работает как в Logcat Android Studio: обычный текст ищется как подстрока, а регулярное выражение включается ключом — `tag~:Net.*`, `-message~:foo|bar`. Переключатель «Regex» убран (раньше текст по умолчанию считался регулярным выражением, и `a.c` находило `abc`). «Match case» (`Cc`) переехал в поле запроса, между очисткой и звездой, как в оригинале. Регулярное выражение — в плагине тоже только через `key~:`.
- JSON-карточка: длинные строки переносятся внутри карточки с висячим отступом, без переноса карточка тянется до конца самой длинной строки.

## 1.3.11 — 2026-10-15
- Раскрытый JSON в логе рисуется карточкой, как на сайте проекта: нейтральный фон, слева полоска цвета уровня, ключи, строки, числа и `true`/`false`/`null` раскрашены цветами редактора IDE (Darcula или Light — по теме приложения). Intent и URL остались обычными строками.
- Плагин 0.1.1: исправлено падение на Android Studio Quail 1 (2026.1) — `NoSuchMethodError` в `PopupProperties`. Плагин собирается против самой старой поддерживаемой платформы (261), и верификатор проверяет его на 261 и 262 (`-PstudioPath` подменяет сборочную Студию локальной).

## 1.3.10 — 2026-10-12
- Устойчивость к сну и блокировке экрана: вызовы adb идут с таймаутом и вне UI-потока (зависший adb больше не замораживает окно при запуске, `Clear` не блокирует интерфейс), список устройств собирается асинхронно, один `getprop` и кэш вместо серии вызовов.

- `UiFreezeWatchdog`: при зависании UI дольше 5 с дамп потоков пишется в `~/.logcactus/freeze.log` — для разбора, если зависание повторится.
- «Save session»: если расширение стёрто, оно дописывается автоматически.
- macOS-сборка подписана Developer ID и нотаризована.

- Отдельный переключатель «Auto-expand long URLs» в Configure view (раньше URL раскрывались вместе с JSON); сохраняется между запусками.

## 1.3.5 — 2026-10-01
- Исправлена потеря первых строк приложения при фильтре `package:mine` / `package:…`: имя процесса (а по нему пакет) для нового pid, например после перезапуска приложения, раньше узнавалось с задержкой до 1,5 с, и ранние строки отбрасывались фильтром. Теперь имя узнаётся сразу; число вызовов `adb shell ps` ограничено (8 за 10 с), чтобы начальный дамп буфера с умершими процессами не тормозил поток.

## 1.3.4 — 2026-10-01

## 1.3.3 — 2026-10-01
- aapt2 зашит в приложение (macOS и Windows), как adb: иконки и названия приложений работают без Android SDK.
- Выбор процесса переживает перезапуск приложения (новый PID, тот же пакет и имя); устаревший результат фонового расчёта фильтра отбрасывается.
- Закладки, краши и раскрытия JSON сбрасываются при смене устройства и Restart; счётчики истории фильтров считаются один раз при открытии меню.
- `view.properties`: вкладки пишут только изменённые поля и сохраняют настройки при закрытии; статус Wi-Fi виден внутри диалога, сбой не блокирует его кнопки.
- Каталог приложений: daemon-потоки, числовая сортировка версий build-tools (34 новее 9), `aapt2.exe` и путь SDK на Windows, сбой adb не блокирует повторную загрузку; один shutdown-hook на все вкладки; убраны неиспользуемые DI-регистрации.

## 1.3.1 — 2026-10-01
Исправления по код-ревью 1.3.0.
- Краш по нехватке памяти при открытии справки/сообщений с патологическим JSON: разбор JSON ограничен по глубине (64) и размеру вывода, кэши Canvas обрезаются по живому набору строк, куча 768 МБ, при OOM дамп кучи пишется в `~/.logcactus`.
- Canvas: вид не «уезжает» при приходе строк после режима слежения, ленивое форматирование не трогает строки далеко под экраном, копирование выделения внутри дерева JSON, F2 по закладкам не залипает.
- Краши: повторный краш/ANR теперь даёт уведомление и счётчик «×N»; libc+DEBUG одного нативного падения — одна запись, сигнатура с процессом.
- Вкладки не делят состояние (`key` по id); у каждой вкладки свой выбор устройства.
- Поток adb: состояние контроллера под замком, устаревшие записи прежней подписки отбрасываются, ошибка строки не обрывает поток, обрыв потока виден в логе, `adb shell ps` с таймаутом.
- Безопасность/надёжность действий: пути и пакеты проверяются перед подстановкой в shell-скрипт (`AppCatalog`), ошибки adb больше не выдаются за успех, «Clear cache» не использует `pm clear --cache-only` на Android < 11, скриншоты в одну секунду не перезаписываются.
- Запросы: явный `&` — И (раньше ИЛИ для одинаковых ключей), неизвестный ключ (`http://x`) — обычный текст, `level:W` — «WARN и выше», невалидный regex ищется как текст.
- Парсер logcat: служебные строки `--------- beginning of …` не записи, pid вне Int не роняет поток, запись за 31 декабря в январе не «из будущего».
- Файлы: настройки, фильтры, история, кэш меток и сессии пишутся атомарно; чтение сессии ограничено последними 100 000 строк с предупреждением.
- Отложено (пока не сделано): сброс выбора процесса при смене PID, слияние `view.properties`, кэш `adb devices`, удаление прежнего списка.

## 1.2.0 — 2026-09-30

Инструменты тестировщика: баг-репорт, закладки, краши и ANR, действия над устройством, сессии и сравнение, Wi-Fi, справка.

### Инструменты тестировщика
- Баг-репорт: кнопка / Cmd(Ctrl)+Shift+C копирует Markdown (устройство, Android, версия приложения, дата, фильтр + лог). Источник строк: закладки, иначе хвост видимых; пункт меню «Copy Bug Report Around This Line».
- Закладки: клик по бейджу уровня, F2 / Shift+F2, выбранные строки подсвечены.
- Свёртка стектрейсов (`▸ N stack frames`, клик раскрывает; переключатель в Configure view); кликабельные URL; «Expand JSON / Intent» в контекстном меню.
- Панель крашей и ANR: группировка одинаковых, счётчик, переход к строке, копирование трейса, уведомление о свежем краше.
- Меню устройства: скриншот (папка + буфер), перезапуск, force stop, очистка данных (с подтверждением), deep link, информация о приложении.
- Сессии `.logcactus`: сохранить, открыть во вкладке, сравнить с текущим буфером (новые/пропавшие ошибки, краши, теги).
- Тултипы на всех кнопках.
- Кнопка «?» открывает справку: хоткеи, мышь, синтаксис фильтра, назначение кнопок.
- Подключение по Wi-Fi: из USB одной кнопкой, pairing по коду (Android 11+), connect по IP:port, поиск в сети.
- «Clear app cache», копирование и выделение текста в App info, уведомление о скриншоте с кнопкой «Open folder».

### Исправления
- Горизонтальная прокрутка при выключенном переносе строк двигает весь список целиком (раньше зажималась в 0 из-за коротких строк среди длинных).
- JSON после префикса (`Body: {…}`) и обрезанный logcat'ом раскрывается автоматически, выровнен под префиксом; переключатель «Auto-expand JSON / Intent».
- Падение при правом клике по строке с активным выделением (`layouts are not part of the same hierarchy`): меню больше не регистрирует свои тексты в выделении.

### Фильтр
- `package:mine` (и `app:mine`) теперь означает приложение, которое сейчас на экране устройства, и следует за ним; чип в поле фильтра, клик закрепляет пакет. Раньше фильтр не находил ничего.

## 1.1.0 — 2026-09-30

### Производительность
- Память: ~300 МБ вместо 1,2–1,6 ГБ (heap ограничен `-Xmx384m`, SerialGC, возврат памяти ОС).
- Рендер логов: при заполненном буфере строки больше не форматируются заново на каждом кадре (`LogRenderCache` понимает сдвиг окна).
- Инкрементальный индекс фильтра/процессов/тегов/пакетов (`LogSnapshotIndex`) вместо полного прохода по 5000 строк на кадр.
- Убраны лишние копии списка логов на каждую строку, чтение `theme.json` с диска на каждую строку и запуск `adb shell ps` на каждую строку с неизвестным pid (теперь троттлинг, в фоне).
- Перекомпонировался весь экран (тулбар) на каждое обновление списка — чтения списка изолированы.
- Частота рендера 30 → 15 Гц; `LazyColumn` со стабильными ключами строк.
- Парсер logcat пропускает regex для строк, не начинающихся с `[`.

### Исправления
- `adb logcat` больше не остаётся висеть после закрытия приложения.
- Дропдаун подсказок: длинные значения (имена процессов и т.п.) не обрезаются; ширина по содержимому.
- Бейдж уровня лога центрируется по вертикали относительно строки.
- Выделение мышью в поле фильтра видно поверх подсвеченного токена (`package:` и т.п.).
- Автоскролл к концу продолжает работать при полном буфере.

### Дистрибутивы
- Windows: adb (`adb.exe` + 2 dll, platform-tools 37.0.1) встроен в приложение — `.msi` работает без Android SDK; `AdbLocator` кроссплатформенный (тест `AdbLocatorTest`).
- `.msi` — major upgrade (ставится поверх предыдущих сборок с тем же `upgradeUuid`).
- `.dmg` только Apple Silicon (arm64); оба дистрибутива не подписаны.

### Технически
- В runtime приложения добавлен `jdk.jfr` (профилирование через `jcmd JFR.start`).
- Добавлены `proguard-rules.pro` и `buildTypes.release.proguard` — `createReleaseDistributable` собирается (меньше размер, по CPU разницы нет).
- Синтетический backend для замеров: `-Dlogcactus.backend=simple -Dlogcactus.simple.rate=N`; `-Dlogcactus.renderMs=N`.
- Юнит-тесты: `LogSnapshotIndexTest`, `LogRenderCacheTest`.
