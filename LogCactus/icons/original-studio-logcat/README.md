# Оригинальные иконки Logcat из Android Studio

Извлечено из `Android Studio.app/Contents/plugins/android/lib/artwork.jar` (Android Studio 2026.1.4, build 261.26222.65). Лицензия — Apache 2.0 (заголовок в каждом svg).

- `logcat.svg`, `logcat_dark.svg` — иконка окна Logcat (16×16), светлая и тёмная темы.
- `logcat@20x20.svg`, `logcat@20x20_dark.svg` — она же для новой UI (20×20).
- `studio/icons/logcat/...` — иконки панели Logcat: избранное, история фильтра, перенос строк, краш приложения.
- `studio/icons/shell/tool-windows/...` — исходное расположение иконок окна.
